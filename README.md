# Cher Micole P. Lirio — Revised Portfolio

A clean, responsive, GitHub Pages-ready portfolio built with plain HTML, CSS, and JavaScript.

## Files
- `index.html` — main portfolio page
- `style.css` — responsive visual design
- `script.js` — mobile navigation, reveal animation, certificate filtering
- `assets/images/` — profile photo
- `assets/certificates/` — unique certificate previews and PDFs

## GitHub Pages
1. Upload the full contents of this folder to the root of the `portfolio` repository.
2. Commit and push to the `main` branch.
3. In GitHub: **Settings → Pages**.
4. Use **Deploy from a branch**, select `main` and `/ (root)`.

The site is fully static and does not require PHP or MySQL.
